A plain-text template for keeping track of a paper. Use it in any Markdown editor, or copy the headings into your existing notebook.

What's inside

  • The question the paper asks.
  • The central result and the evidence behind it.
  • Assumptions, open questions and possible next steps.

The download is a small Markdown file with no software dependencies.

How to use it

Make one copy per paper. Start with a sentence in your own words, then add only the details you expect to need again.

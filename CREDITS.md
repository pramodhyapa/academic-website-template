## What is included in this repository

- A new Python static-site generator, HTML shell, CSS and browser JavaScript.
- Fictional sample content for Bodhi B. Björn at a fictional institution.
- Original geometric SVG illustrations generated by `tools/make_art.py`.
- A fresh, seeded network graphic. It does not trace the earlier background PNG
  or reuse coordinates extracted from that image.
- A short sample Markdown download and an illustrative wave animation.
- GitHub Actions configuration and documentation for using the starter.

## What is excluded

No Sciento, Future Imperfect or Mundana source code, stylesheets, theme images,
portraits, font files or icon packs are bundled. No Bootstrap, jQuery, Plotly,
Three.js or other vendor library is bundled. Typography uses installed system
fonts. The site makes no font-service or analytics requests.

The author's personal research articles, CV, publications, slides, photographs,
research data and website archives are not included. Author attribution in this
documentation is intentional.

## Release review

Reviewed for the initial release on 18 November 2026. The source inventory,
asset-generation code, page shell and browser interactions were checked against
the earlier provenance audit. Included assets were regenerated from the new
formula-based/seeded artwork generator, and no theme source or vendor bundle
was found in the release. MIT applies to this starter's included material; it
does not relicense the historical themes or assert rights over outside work.

When adding an image, dependency or contributed asset, record its author,
source, licence and modifications here, and retain any required notices.
